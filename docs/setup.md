# Setup

## Accounts

- **ODP Academy** ([academy.hubocean.earth](https://academy.hubocean.earth/)): the lessons, assignments, meetings and certificates.
- **Ocean Data Platform** ([app.hubocean.earth](https://app.hubocean.earth/)): the Catalog, My Data and Workspaces. Sign-in is by a link sent by e-mail, with the same address as ODP Academy.

## Tools

- **QGIS**, for Module 2. GeoJSON downloads open directly as a layer; OGC API Features connections are added from the Data Source Manager.
- **ODP Workspace**, for Module 3: a hosted JupyterHub with the ODP packages already installed. Python packages are added with `pip`, R packages with `install.packages()`.
- **SeaSketch**, for Module 4.

## This site

Built with [MkDocs](https://www.mkdocs.org/) and [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/). A push to `main` rebuilds it through GitHub Actions. Course downloads and screenshots stay on my computer and are not in the repository.
