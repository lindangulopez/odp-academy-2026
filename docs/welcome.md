## The three areas of ODP

The Getting Started lesson introduces the Ocean Data Platform through its three main areas:

- **Catalog**: where you find datasets. You can search, filter, read the metadata and look at the data on a map.
- **My Data**: your own storage space, to organise datasets, manage access, work with others and prepare data for sharing or publication.
- **Workspaces**: cloud analysis environments with Jupyter notebooks, Python and R, so large datasets don't need your own computer.

A typical workflow starts in the Catalog, moves to a Workspace for the analysis, and ends in My Data, where the results are stored and shared.

ODP can be explored without an account. An account adds downloads, My Data, Workspaces and a personal API key for the later modules. ODP Academy (the lessons) and the Ocean Data Platform (the data) are two websites that use the same e-mail address.
